# 待实现部分与建议顺序

本工程已经接通 Center 协议、观察保存和交互记录；模型、损失函数、优化循环、奖励以及评估规则保留给你实现。`NotImplementedError` 表示尚未完成的接口，不会产生伪造的训练结果。

## 一、先确定训练样本是什么

先考虑行为克隆：输入当前画面或一段连续画面，预测转向、油门与刹车。每条记录的正确关系是 `observation → action`，后续观察 `next_observation` 用于分析动作结果；不能把动作执行后的画面当作该动作决策时已知的输入。

`collect` 只获取图片，是无标签数据；可用于图像预训练、人工标注和查看赛道。Center 当前没有精确记录玩家键盘、实体手柄或浏览器控制事件的训练日志接口。每五秒上报的手柄状态不是逐帧标签。要获得人工示范，需要另行实现统一的示范控制入口，在发出操作的同时保存当时的观察和动作；若玩家使用实体设备，则需实现设备采样与时间对齐。

`rollout` 保存的是你指定策略通过 Center 发出的请求动作及 ACK，可以用于交互学习或管道验证。中立策略只验证协议和数据格式，不构成有驾驶能力的训练集。ACK 表示虚拟手柄提交成功，不代表车辆已转弯、未碰撞或获得了奖励。

## 二、实现数据读取和预处理

在 `src/data/dataset.py` 实现记录读取、缺失文件检查、图像解码和序列采样。优先按完整 episode 或驾驶片段划分训练集和验证集，避免同一段连续画面的邻近帧同时进入两者。未标注记录不能混进监督学习的动作标签。

在 `src/data/preprocessing.py` 实现输入裁剪、缩放、RGB 转换、归一化和时序窗口。训练与在线推理使用相同的预处理规则；窗口不能跨越 terminal `session_id` 或数据片段边界。`src.model` 的默认输入约定是 `[B, N, 3, H, W]`，原有模型 README 说明了形状和掩码。

## 三、实现驾驶策略

先完成 `src/model/` 中原有的视觉模型。它输出特征，尚不能直接输出手柄操作。随后在 `src/policies/driving.py` 接入视觉模型与动作头，将特征映射为 `Action`：转向限制在 `[-1, 1]`，油门与刹车限制在 `[0, 1]`，动作保持时间使用毫秒。

模型推理不要放在 Center 内部。AI 通过 `src/integrations/center/` 获取 JPEG 和发送动作；WebRTC 用于人看的视频预览，其解码和显示缓冲不作为训练图像时间来源。`run_rollout` 已在线程执行同步 `predict`，由网络事件循环负责响应和取消。

## 四、实现离线训练

在 `src/training/bc.py` 依次补齐数据加载、网络与动作头、损失函数、优化器、训练循环、验证和 checkpoint。可先只回归转向，再扩展油门与刹车。实验参数和预处理配置应随 checkpoint 一起保存，推理时读取同一份配置。

入口 `auto-driver-ai train-bc` 仅将参数交给 `BehaviorCloningTrainer.fit()`。当前执行会明确提示待实现的位置；不会自动训练一个占位模型。已有 CUDA 环境可用 `uv run python check_env.py` 检查。

## 五、再扩展交互训练

在 `src/training/rl.py` 实现算法，在 `src/training/reward.py` 接入奖励和终止条件。Center 的 `step` 只保证：动作 ACK 的执行时间加保持时长之后，才返回新采集的观察。游戏持续运行，网络、采样与调度都会耗时，因此它不是确定性的游戏物理帧推进接口。

车速、进度、偏离赛道、碰撞及比赛结束，需要你从游戏遥测、视觉识别或额外采集源获得。Center 不提供这些状态，不提供 reward、done 或自动重置比赛；框架中的空奖励不能被当作零奖励。训练环境应另行实现 reset，以及断线、超时和人为停止对应的截断处理。

## 六、实现评估和部署

在 `src/evaluation/` 定义固定赛道和场景，记录完成率、碰撞、偏离、控制频率和时延。先在离线数据评估，再使用指定测试终端验证。在线运行时，把 `NeutralPolicy` 换为实现后的 `DrivingPolicy`，继续复用 Center 客户端和 rollout 记录器。

观察上传频率由游戏电脑 `TERMINAL_OBSERVATION_FPS` 控制，默认 10 FPS；视频默认 60 FPS，两者独立。提高视觉控制频率前，先实测采集、推理和网络耗时，再调整观察频率及 `duration_ms`，不要把视频播放 FPS 当成 AI 的可用观察频率。
