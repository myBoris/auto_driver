操作说明

按住屏幕按钮或 Enter 操作，松开释放。Space 释放全部输入。

赛车模式提供三只踏板：按住并向下拖动增加力度，松开立即归零。方向键微调，End 踩满，松键归零；Home、↺ 可释放该踏板，Space 清空全部输入。触摸取消或失焦也会释放。

键盘使用 WASD / 方向键驾驶，C 离合，Q 降挡、E 升挡。展开“按键力度”可设置 W / S / C 的按住力度；普通键盘无法感知按压力。

方向盘和转向滑块松手或松键自动回正；方向盘 Home 也可回正。换挡对应 X / B。游戏需开启手动挡＋离合，并将 LB 绑定为离合；当前虚拟手柄的离合仅支持开关，0% 松开，非零踩下。

标准实体手柄：左摇杆转向，RT 油门、LT 刹车，LB 离合；扳机旁同步显示力度。连接后按任意键识别，浏览器需支持 Gamepad API，通常需通过 HTTPS 或 localhost 访问。

切换模式、终端或窗口失焦时自动释放本地输入；实体手柄需回中后恢复。API 执行的驾驶动作会同步显示，查看状态和切换控制方式不影响 API 输入。离合按 LB 开关显示为 0% 或 100%。
